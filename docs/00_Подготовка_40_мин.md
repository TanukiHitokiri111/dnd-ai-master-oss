0.6. 📌 Блок «Если у вас Windows (WSL2)» — прочитать обязательно

В WSL2 есть две особенности, которые сломают план, если их не учесть:

1. USB-телефон не виден в WSL. Лечится через usbipd (PowerShell от администратора, в Windows):

winget install usbipd
usbipd list                      # найдите BUSID телефона, например 1-4
usbipd bind --busid 1-4
usbipd attach --wsl --busid 1-4
powershell


После этого adb devices внутри WSL увидит телефон. После каждой перезагрузки Windows — повторять attach.


2. Телефон не достучится до бэкенда в WSL2 (у WSL своя NAT-сеть). Решение — проброс порта (PowerShell от администратора):

# узнайте IP WSL: в терминале WSL выполните  hostname -I
netsh interface portproxy add v4tov4 listenport=8000 listenaddress=0.0.0.0 connectport=8000 connectaddress=172.x.x.x
New-NetFirewallRule -DisplayName "WSL2-8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
powershell


В приложении указывайте IP Windows-машины (команда ipconfig → IPv4). ⚠️ IP WSL меняется после перезапуска — portproxy нужно будет обновлять.
