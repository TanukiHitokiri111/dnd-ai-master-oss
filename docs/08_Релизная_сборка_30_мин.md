8.1. Keystore (один раз, хранить ВЕЧНО)

keytool -genkey -v \
  -keystore ~/rpg-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias rpg
bash


Ответьте на вопросы (можно любые), задайте пароль и запишите его.


⚠️ Потеряли keystore = навсегда потеряли возможность обновлять приложение в Google Play. Скопируйте файл на флешку/в облако. Файл уже закрыт от git корневым .gitignore (*.jks).

8.3. android/app/build.gradle — точечные правки

Файл уже существует (его создал flutter create). Не заменяйте целиком — отредактируйте три места:

1. Сразу ПОСЛЕ блока plugins { ... } вставьте:

def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}
groovy


2. Внутри блока android { ... } (например, сразу после namespace) добавьте:

signingConfigs {
    release {
        keyAlias keystoreProperties['keyAlias']
        keyPassword keystoreProperties['keyPassword']
        storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
        storePassword keystoreProperties['storePassword']
    }
}
groovy


3. Найдите блок buildTypes { ... } и замените его целиком на:

buildTypes {
    release {
        signingConfig signingConfigs.release
        minifyEnabled true
        shrinkResources true
        proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
    }
}
groovy


8.4. android/app/proguard-rules.pro (🔴 раньше отсутствовал — без него релиз падает)

# Flutter engine и плагины
-keep class io.flutter.** { *; }
-keep class io.flutter.plugins.** { *; }

# Аннотации и generics — нужны плагинам с рефлексией
-keepattributes Signature, *Annotation*, EnclosingMethod

# Известные безобидные предупреждения
-dontwarn org.conscrypt.**
-dontwarn javax.annotation.**
proguard


8.5. Сборка и установка

cd ~/projects/dnd_ai/rpg_client
flutter build apk --release
# результат: build/app/outputs/flutter-apk/app-release.apk (~20–25 МБ)

adb install build/app/outputs/flutter-apk/app-release.apk
bash


Для Google Play (потом): flutter build appbundle --release.


⚠️ Перед релизом для «боевого» сервера смените baseUrl в app_config.dart на HTTPS-домен (Этап 9) и пересоберите!
