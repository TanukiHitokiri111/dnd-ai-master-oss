# Этап 12. Устранение неполадок

ЭТАП 12. Устранение неполадок

Симптом	Причина	Решение
«Нет связи с сервером» в приложении	Разные сети / неверный IP / DHCP сменил IP	hostname -I; сверить IP в app_config.dart и network_security_config.xml; выключить VPN на телефоне
Cleartext HTTP traffic not permitted	Не подключён network config	Проверить строку android:networkSecurityConfig в манифесте (7.1)
(WSL2) телефон не видит бэкенд	NAT WSL2	Этап 0.6: portproxy + правило firewall; IP WSL сменился → пересоздать portproxy
(WSL2) adb devices пуст	USB не проброшен	Этап 0.6: usbipd attach --wsl --busid ...
Контейнер падает с ModuleNotFoundError	Старый Dockerfile с /root/.local	Использовать Dockerfile из Этапа 4.1 (--prefix=/install)
docker compose ps → unhealthy	Бэкенд упал внутри	docker compose logs backend — смотреть последнюю ошибку
401 от OpenAI	Неверный/просроченный ключ	Пересоздать ключ, исправить .env, docker compose restart
429 от OpenAI сразу при первом запросе	Нулевой баланс	Billing → пополнить на platform.openai.com
429 с текстом «Слишком много запросов»	Сработал наш rate-limiter	Подождать 60 сек (это защита, всё ок)
422 на любой запрос	Пустое/пробельное поле	Pydantic-валидация; проверьте JSON в запросе
systemd: status=1/FAILURE сразу после старта	Часто — битый .env или EnvironmentFile	journalctl -u rpg-backend -n 50; убедиться, что EnvironmentFile убран (9.3)
ValidationError на CORS_ORIGINS	Кавычки съедены systemd	Тот же фикс: pydantic читает .env сам
certbot: Failed authorization	DNS не настроен/не разошёлся	ping your-domain.com → должен быть IP сервера; ждать
flutter doctor: licenses not accepted	Лицензии не приняты	flutter doctor --android-licenses, везде y
Gradle просит android-35	Новый Flutter → новый compileSdk	sdkmanager "platforms;android-35" "build-tools;35.0.0"
_$ChatMessageFromJson не найден	Не сгенерирован freezed-код	dart run build_runner build --delete-conflicting-outputs
flutter analyze ругается на withOpacity	Flutter новее 3.27: метод deprecated	Не ошибка, а предупреждение; можно заменить на .withValues(alpha: x)
История «забывается» между сообщениями	Запущено >1 gunicorn-воркера	Строго --workers 1 (или Redis — Этап 13)
port is already allocated	Порт 8000 занят	sudo lsof -i :8000 → завершить процесс или сменить порт
Шрифты не отображаются	Нет интернета при 1-м запуске	Дать интернет; google_fonts закэширует шрифты
Потерян keystore	—	Обновления в Google Play невозможны навсегда. Бэкапьтесь!
